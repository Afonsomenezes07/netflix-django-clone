# 🎬 Netflix Django Clone

Projeto inspirado na Netflix, desenvolvido com **Python, Django e React**, com foco em arquitetura backend, APIs REST e integração com frontend moderno.

---

## 🚧 Status do Projeto

🚀 Em desenvolvimento

---

## 📌 Sobre o Projeto

O objetivo deste projeto é simular uma plataforma de streaming, permitindo o gerenciamento de usuários, catálogo de filmes, categorias e histórico de visualização.

Este projeto está sendo desenvolvido como parte de estudos em:

- Desenvolvimento backend com Django
- Construção de APIs REST
- Integração com frontend (React)
- Boas práticas com Git e GitHub

## ⚙️ Como Executar o Projeto

### 1️⃣ Clonar o repositório

git clone https://github.com/Afonsomenezes07/netflix-django-clone.git
cd netflix-django-clone

### 2️⃣ Criar ambiente virtual

python -m venv venv

### 3️⃣ Ativar ambiente virtual

Linux/macOS:

source venv/bin/activate

Windows:

venv\Scripts\activate

### 4️⃣ Instalar dependências

pip install -r requirements.txt

### 5️⃣ Rodar migrations

python manage.py migrate

### 6️⃣ Iniciar servidor backend

python manage.py runserver

## 🌐 Executar o Frontend

cd frontend
npm install
npm start
