# Netflix Django Clone

Projeto inspirado na Netflix desenvolvido com **Python e Django**.

O objetivo do projeto é praticar desenvolvimento backend, arquitetura de aplicações web e construção de funcionalidades de uma plataforma de streaming.

---

## 🚀 Tecnologias utilizadas

- Python
- Django
- SQLite
- HTML / CSS
- Git & GitHub

---

## 📂 Estrutura do Projeto
```
netflix-django-clone
│
├── config
├── movies
├── users
├── categories
├── watch_history
├── .gitignore
└── manage.py
```
---

## ⚙️ Como executar o projeto

1️⃣ Clone o repositório


git clone https://github.com/Afonsomenezes07/netflix-django-clone.git


2️⃣ Entre na pasta do projeto


cd netflix-django-clone


3️⃣ Crie e ative o ambiente virtual


python -m venv venv
source venv/bin/activate


Windows:


venv\Scripts\activate


4️⃣ Instale as dependências


pip install -r requirements.txt


5️⃣ Execute as migrations


python manage.py migrate


6️⃣ Inicie o servidor


python manage.py runserver
